# Teacher portal V3

The teacher mock store now has many classes, a selected class id, materials, and parent contact fields. Late and behavior points are gone. Homeroom is `isClassTeacher` on the class, and that flag hides the roster tab and class announcements for subject-only classes.

Screens under `apps/mobile/app/(teacher)` all read `selectedClassId`. Settings can add or remove classes, periods, and students, and open a parent directory. Tests can target a subset of the class. Direct reports go to a parent or the school admin.

Verified with `npx tsc --noEmit` in `apps/mobile` on 2026-09-26. Expo Go was not re-run in this pass, so spring and haptic feel still need a device check.
